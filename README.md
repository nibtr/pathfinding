# pathfinding

A simple visualizer for commonly used pathfinding algorithms for
educational purposes.

![image](https://github.com/user-attachments/assets/0dbca496-46e2-421c-a179-0725bfb56bc6)

## Algorithms available

- BFS
- DFS
- Dijkstra
- A\*
- Beam
- Greedy
